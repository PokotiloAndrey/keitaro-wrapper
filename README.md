# Keitaro Workshop

Обёртка над Keitaro Admin API. FastAPI, SQLAlchemy 2, Alembic, SQLite и HTML/JavaScript без сборки фронтенда.

## Возможности

- Создание кампании с доменом, группой и источником. Префикс имени берётся из конфигурации.
- Первый поток фильтрует указанную страну и перенаправляет на Google. Поток по умолчанию ведёт на выбранный оффер.
- Добавление, отключение и возвращение офферов через локальный черновик.
- Автоматическое распределение 100% между активными офферами. Например, 33/33/34. Долю можно закрепить; остаток делится между остальными.
- Отмена черновика, отправка в Keitaro, повторное чтение для проверки результата.
- Защита от повторного создания по request_id, конфликта ревизий черновика и изменения потока в Keitaro с момента загрузки.
- Журнал операций в БД. Операции с неизвестным результатом не повторяются автоматически.

## Запуск (Python 3.12)

```sh
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Заполните `KEITARO_URL`, `KEITARO_API_KEY`, `APP_PASSWORD`. URL — корень сервера без `/admin`. Пароль приложения задаётся отдельно от пароля Keitaro. Ключ не передаётся браузеру. Не добавляйте `.env` в Git.

```sh
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Откройте http://127.0.0.1:8000 и войдите с `APP_USER` / `APP_PASSWORD`. Для Windows можно запустить `setup.cmd`, заполнить созданный `.env`, затем запустить `start.cmd`.

Перед созданием в Keitaro должны существовать доступные пользователю домен, группа кампаний, источник и оффер. Приложение не создаёт эти общие объекты и не меняет чужие кампании. Если список пуст, администратор должен выдать доступ или подготовить объект.

## Демо без Keitaro

Установите `DEMO_MODE=true` и свой `APP_PASSWORD` в `.env`. Миграции и запуск те же. Демо явно отмечено на экране, не отправляет сетевые запросы и хранит имитацию Keitaro в памяти процесса. После перезапуска демо эта память сбрасывается; локальные черновики в SQLite остаются. Используйте отдельную БД для демо, например `DATABASE_URL=sqlite:///./demo.db`.

## Миграции

```sh
alembic upgrade head
alembic current
# Откат удалит локальные черновики и журнал, предварительно сделайте копию БД:
alembic downgrade base
```

Приложение не создаёт таблицы автоматически. Начальная миграция лежит в `migrations/versions/001_initial.py`.

## Проверка

```sh
python -m pytest -q
```

Тесты подменяют Keitaro локальным адаптером: проверяют потоки, фильтр страны, проценты, идемпотентность, черновики, конфликты, частичный сбой, авторизацию и запрет изменения чужих кампаний. Они не являются доказательством живой интеграции.

**Текущий статус:** локальные проверки выполнены. Живая проверка API не завершена: сервер тестового Keitaro возвращает HTTP 403 с кодом 1010 из среды разработки. Нужен повторный запуск с разрешённого компьютера/сервера. Секреты, адрес тестового сервера и содержимое его кампаний не включены в репозиторий.

## Поведение при ошибках

Создание начинается с выключенной кампании. После создания обоих потоков она включается. При ошибке сохраняется журнал и ID, если он уже получен. Частично созданная кампания остаётся для ручной проверки. Если ответ потерян при включении, состояние может быть неизвестно — журнал не утверждает, что запись не состоялась.

Удаление оффера в редакторе означает `state=disabled` и долю 0, сам объект оффера в Keitaro не удаляется. Последний активный оффер убрать нельзя. При отправке меняется только массив offers, фильтры, лендинги и остальные настройки потока сохраняются.

## Ограничения

- Один процесс (`--workers 1`): операции записи сериализуются внутри приложения. Для нескольких процессов нужны блокировки в общей БД.
- Между проверкой свежести и PUT в Keitaro остаётся окно гонки, поскольку атомарный compare-and-swap Keitaro здесь не используется. Не редактируйте тот же поток одновременно в других системах.
- Скринкаст использован как ориентир черновиков, отключения/возврата и долей. Графики и статистические колонки видео не воспроизведены. Цифры интерфейса относятся к распределению трафика, не к финансовой статистике.
- Включение/выключение сохранённых офферов и типы потока требуют живой проверки на версии Keitaro работодателя.
- Basic Auth рассчитана на локальный запуск. При публикации приложения нужны HTTPS, ограничение доступа и секреты окружения. Документация `/docs` не содержит ключей.
- Публичный репозиторий содержит код, не готовые доступы.

API-контракт: https://admin-api.docs.keitaro.io/ . Основные маршруты: `/campaigns`, `/streams`, `/campaigns/{id}/streams`, `/offers`, `/domains`, `/groups`, `/traffic_sources`.
